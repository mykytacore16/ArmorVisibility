# Loadout Visibility

tModLoader 1.4.4 mod.

Adds visibility toggles (eye icons) to the armor, vanity armor and vanity accessory slots, like functional accessories have.
Hidden armor keeps its defense and set bonuses. Works in multiplayer.
Hotkeys can be bound in Controls (unbound by default).

Добавляет «глазики» видимости к слотам брони, украшений и аксессуаров-украшений, как у обычных аксессуаров.
Скрытая броня сохраняет защиту и бонусы. Работает в мультиплеере.
